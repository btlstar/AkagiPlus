# 一番街：AI 与本地装扮

支持 Windows 独立客户端。游戏和 AI 已由用户实际游玩验证；第二版本地装扮经用户反馈目前未发现问题。好感度、觉醒语音试听修复仍待游戏复测。

## 日常启动

1. 打开 Proxifier。
2. 打开发布包 `AkagiPlus.exe`（源码开发使用 `start.bat`），在 AkagiPlus 选择一番街并启用 MITM 捕获。
3. 在「总览」选择麻雀一番街，点击「启动游戏」。程序会自动等待捕获就绪，最多 25 秒；Proxifier 保持运行。
4. AI 在「机器人」配置；进入对局后在原有对局页/悬浮窗查看建议。
5. 退出时先关游戏，再关 AkagiPlus。不需要额外保留命令窗口。

本地装扮直接使用游戏中的角色、皮肤、头像、称号和装扮方案界面，选择按账号保存在本机。当前方案不保证他人视角也能看到；复杂随机方案仍未完整适配。

## 补丁维护

「装扮 → 一番街 · 本地装扮」提供安装/更新、还原、刷新状态。它不是日常启动入口；当前机器已安装，无需每次操作。安装或还原前先退出游戏。

安装器只处理已核对版本的一个 Lua 资源文件，先备份、校验，再替换。游戏更新或出现未知热更新资源时会拒绝覆盖，应重新适配。GUI 使用当前用户 `AppData/Roaming/akagiplus/riichicity-local` 保存原文件与恢复记录；首次会核验并接管此开发目录的旧备份。请勿删除恢复备份。详见[本地装扮说明](../plugins/riichicity_local/README.md)。

## Proxifier

当前本机入口：**HTTPS（HTTP CONNECT）127.0.0.1:23410，无认证**。

规则从上到下：

1. Localhost → Direct：`localhost`、`127.0.0.0/8`、`::1`。
2. `AkagiPlus.exe`（源码运行时为 `akagi.exe`）、`RiichiCityUnlock.exe` → Direct。
3. `Mahjong-JP.exe` → 上述本机 HTTPS 代理，目标地址/端口 Any。
4. Default → Direct。

`41110` 是连接可选外部 RiichiCityUnlock 的内部端口，不是 Proxifier 的游戏入口。日常启动统一使用 GUI。

## 外部 RiichiCityUnlock

原有外部插件接入保留为可选方案，现有配置仍可使用。它的免费模式需要手填 ID，不等于本项目的原生界面本地补丁。本项目不改变原工具的授权模式。

「装扮 → 一番街 · RiichiCityUnlock」中配置完整工具 exe；游戏程序选择 `Game/Mahjong-JP.exe`，不要选择启动器。使用 Proxifier 时无需 proxinject。外部插件公共 CA 默认取用户目录 `.mitmproxy/mitmproxy-ca-cert.pem`，供 Akagi 校验插件；它与游戏需要信任的 Akagi CA 不同。

## 常见问题

- **10061／服务未就绪**：确认一番街、MITM 捕获已启用；若配置了外部插件，也应等待其「已就绪」。新入口会明确指出缺少哪个服务。
- **BadCertificate**：游戏需信任本项目公共证书 `target/debug/ca/akagi-ca.cer`。如尚未导入，可双击安装到当前用户「受信任的根证书颁发机构」，核对名称 Akagi Proxy CA。不要导入私钥文件。
- **候场/详情页是特殊皮肤，入场及牌桌变成默认皮肤**：检查游戏自带的「安全模式」。开启且包含自己时，客户端会在进桌阶段把皮肤设为默认；关闭对自己的处理即可保留所选皮肤。补丁遵循这个设置，不强行覆盖。
- **补丁安装后没有变化**：先完全退出游戏再启动，检查补丁管理中的状态。客户端会缓存已加载的 Lua。
- **升级后拒绝安装**：不要跳过版本检查或强行覆盖，保留当前文件用于适配。

私人路径、装扮选择与 AI 密钥在本机忽略目录中。完整日志可能含账号资料，不要直接公开。开发检查按[验证指南](VALIDATION.md)选择受影响部分；常规小改动不需要运行全部检查。

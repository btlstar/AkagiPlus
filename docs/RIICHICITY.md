# 麻雀一番街：AI 与 RiichiCityStyle

支持 Windows 独立客户端，AI 通过 MITM 捕获连接。本地装扮由 [RiichiCityStyle](https://github.com/btlstar/RiichiCityStyle) 提供，装扮本身无需代理；头像、语音及随机方案的覆盖范围有限。

## 日常启动

1. 打开 Proxifier。
2. 打开发布包 `AkagiPlus.exe`（源码开发使用 `start.bat`），在 AkagiPlus 选择一番街并启用 MITM 捕获。
3. 在「总览」选择麻雀一番街，点击「启动游戏」。程序会自动等待捕获就绪，最多 25 秒；Proxifier 保持运行。
4. AI 在「机器人」配置；进入对局后在原有对局页/悬浮窗查看建议。
5. 退出时先关游戏，再关 AkagiPlus。不需要额外保留命令窗口。

本地装扮直接使用游戏中的角色、皮肤、头像、称号和装扮方案界面，选择按账号保存在本机。当前方案不保证他人视角也能看到；复杂随机方案仍未完整适配。

## 补丁维护

内置 RiichiCityStyle 在「装扮 → 一番街 · 本地装扮」提供安装/更新、还原、刷新状态。它不是日常启动入口。安装完成后无需每次启动都操作。安装或还原前先退出游戏。

安装器只处理已核对版本的一个 Lua 资源文件，先备份、校验，再替换。游戏更新或出现未知热更新资源时会拒绝覆盖，应重新适配。GUI 使用当前用户 `AppData/Roaming/akagiplus/riichicity-local` 保存原文件与恢复记录。请勿删除恢复备份。详见[本地装扮说明](../plugins/riichicity_local/README.md)。

## Proxifier

默认本机入口（以设置中的地址为准）：**HTTPS（HTTP CONNECT）127.0.0.1:23410，无认证**。

规则从上到下：

1. Localhost → Direct：`localhost`、`127.0.0.0/8`、`::1`。
2. `AkagiPlus.exe`（源码运行时为 `akagi.exe`） → Direct。
3. `Mahjong-JP.exe` → 上述本机 HTTPS 代理，目标地址/端口 Any。
4. Default → Direct。

日常可从 AkagiPlus 的「总览」启动游戏。

## 常见问题

- **10061／服务未就绪**：确认一番街、MITM 捕获已启用。
- **BadCertificate**：游戏需信任所配置 CA 目录下的公共证书 `akagi-ca.cer`（默认 `ca/akagi-ca.cer`）。如尚未导入，可双击安装到当前用户「受信任的根证书颁发机构」，核对名称 Akagi Proxy CA。不要导入私钥文件。
- **候场/详情页是特殊皮肤，入场及牌桌变成默认皮肤**：检查游戏自带的「安全模式」。开启且包含自己时，客户端会在进桌阶段把皮肤设为默认；关闭对自己的处理即可保留所选皮肤。补丁遵循这个设置，不强行覆盖。
- **补丁安装后没有变化**：先完全退出游戏再启动，检查补丁管理中的状态。客户端会缓存已加载的 Lua。
- **升级后拒绝安装**：不要跳过版本检查或强行覆盖，保留当前文件用于适配。

私人路径、装扮选择与 AI 密钥在本机忽略目录中。完整日志可能含账号资料，不要直接公开。

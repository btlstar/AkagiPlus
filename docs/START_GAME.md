# 打开游戏

发布版：完整解压后双击 AkagiPlus.exe。源码开发：运行 start.bat。

在「总览」右上角选择游戏并点击「启动游戏」；「对局」顶部也有同一入口。捕获未就绪时程序会先等待，正在启动时不接受重复点击；游戏运行后可点击「返回游戏」。

- 雀魂：启用 MajsoulMax 时使用 MITM，打开专用浏览器。登录资料与普通浏览器独立。
- 一番街：保持 Proxifier 运行，使用已有规则。客户端应选择 Game/Mahjong-JP.exe，可点击启动入口旁的配置按钮。无需启动命令窗口。
- 掌心全民麻将：先完成官方更新，退出后在「装扮」安装 ZhangxinPlus，随后从 GUI 启动并在新对局开始前连接 AI。
- 天月麻雀：选择 mahjongP.exe，启动后等待登录；AmatsukiStyle 默认启用并恢复本地大厅选择，普通立直 AI 须在新对局开始前连接，无需代理或证书。
- 天凤：使用浏览器捕获与对应 AI，在新对局开始前连接。
- 本地装扮：RiichiCityStyle 与 ZhangxinPlus 的安装、更新和还原都在「装扮」页，先退出游戏再操作；MajsoulMax 与 AmatsukiStyle 在装扮页启用。
- 更换平台：先结束当前对局。启动选择和设置页共用同一平台配置。
- 「重新连接」／重启捕获：用于连接维护，无需每次开游戏都点击；对局中操作可能丢失当前牌局信息。

一番街出现默认皮肤时，先检查游戏安全模式是否包含自己。

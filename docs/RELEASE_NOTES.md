# AkagiPlus 3.8.0 · Plus 2

基于 Akagi 3.8.0 的首次 Windows x64 便携预发布版，集成近期已验证的多平台 AI、游戏启动与本地装扮功能。

## 本版内容

- 在总览和对局页提供 GUI 游戏启动与返回入口。
- 集成雀魂 MajsoulMax、一番街本地装扮及掌心 ZhangxinPlus 0.1.5。
- 掌心通过本地消息接入 AI，友人局普通立直三麻、四麻已实测，无需 Proxifier 或证书。
- 掌心支持角色、皮肤、桌布、牌背、麻将牌、立直棒、特效、表情、音乐、称号、头像框及装扮方案，按账号保存在本机。
- 修复方案使用时的 ID 兼容及失败回调、红五显示排序、玩家区域滚动条反复切换。
- 更新 README、截图、许可与便携打包；发布包生成空白默认配置。

## 下载与使用

下载 `AkagiPlus-3.8.0-plus.2-windows-x64.zip`，完整解压后运行 `AkagiPlus.exe`，保留相邻目录。另附 `.zip.sha256`。系统要求 Windows x64 与 WebView2；无须另装 Python 或 Node。AI 密钥和模型由用户配置。

掌心先正常启动并完成官方更新，退出后在「装扮」安装 ZhangxinPlus。目前适配资源 **92217**。一番街需自行安装并配置 Proxifier；雀魂使用专用浏览器及对应捕获模式。

## 范围与更新

掌心特殊玩法、中途对局恢复及自动操作未支持，头像与语音仍未完整适配。一番街安全模式若包含自己，会在进桌时显示默认皮肤。本地装扮不增加服务器拥有物或养成进度，也不保证他人视角可见。

未知游戏资源更新会拒绝安装；保留原始备份以便还原。更新前退出程序和游戏、备份个人配置，下载完整套件。

发布包不含个人密钥、登录资料、代理证书、日志或游戏资源。MajsoulMax 对应源码、许可和来源记录随包提供。外部 RiichiCityUnlock、Proxifier 和游戏客户端不随包提供。

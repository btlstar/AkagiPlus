# 开发验证指南

按改动范围选择检查，不在每次开发后追加排查流水账。一般只记录变更内容、相关检查结果和实际限制。

| 改动 | 必要检查 |
|---|---|
| 文案、样式、文档 | 对应界面预览或文档检查 |
| 一番街本地装扮 Lua | 生成一次暂存包；运行 `plugins/riichicity_local/test_lua.py <游戏目录> --bundle <暂存包>` |
| 补丁安装/恢复 | 另运行 `plugins/riichicity_local/test_install.py` |
| 游戏启动器 | 运行原生 `ipc::game_launcher` 回归和对应前端启动组件检查 |
| MajsoulMax 协议处理 | 运行 `tests/test_majsoulmax_worker.py`；桥接有改动时再运行独立 Rust 桥测试 |
| Rust 代理/进程管理 | 运行受影响的 Rust 回归及编译检查；仅在实际链路变更时做对应联调 |
| 前端功能 | 对应组件测试/类型检查；发布或构建相关改动再做完整构建 |

已通过的检查不反复重跑；出现新改动、失败或未解决疑点时才补充验证。安装器的原文件备份和摘要校验属于恢复机制，每次真实安装仍保留。

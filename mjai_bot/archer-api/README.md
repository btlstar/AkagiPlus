# Archer API 三麻 / 四麻插件

适用于 AP（AkagiPlus）的外部机器人接口。已在雀魂、天凤、一番街、掌心和天月的普通立直对局中联调三麻、四麻，包括三麻拔北；各平台仍需满足 AP 捕获条件。
原版 Akagi 可尝试安装基础机器人接口，但本文所述局前检查、合法动作过滤和悬浮窗功能需要对应新版 AP。

## 安装与配置

在“机器人”页点击“从 ZIP 安装”，选择 archer-api.zip。
双击插件目录 configure.cmd，使用 Windows 默认浏览器打开独立本机配置页面。重复打开会复用正在运行的配置服务：

1. 填入 Archer 专用 API 密钥，点击“查询模型与余额”（不消耗 Token）。
2. 分别选择四麻模型、三麻模型，保存配置。两者不能混用。
3. 可分别点击四麻 / 三麻测试按钮，各发起一次付费示例决策。
4. 回到 AP 刷新列表；若环境未安装，先点击“安装环境”，然后为“Archer API · 三麻 / 四麻”同时启用两个模式的开关。

同一个插件按新对局人数自动选择模型，无须每次切换设置。
配置也可在机器人列表的插件配置入口修改。修改从下一个新对局生效。
不要将 Archer 密钥填入顶部 MJOT 专用设置。Token 与客户端场次、月卡分开计费。
三麻模型列表可用不代表实时服务一定正常；模型加载、忙碌或超时会显示暂无建议。

## 局前连接状态

启用 Archer 后，悬浮窗在对局开始前自动检查密钥、已启用模式的模型及账户余额。
检查只访问模型列表和余额接口，不调用推理，不消耗 Token。
正常时显示“连接正常”和三四麻模型；异常时显示原因，可点击“重新检测”。
空闲时每分钟刷新一次，修改 AP 机器人设置后立即刷新。进入对局后切回动作建议。
“连接正常”表示账号接口可用，实际模型推理仍以对局返回为准。

## 建议与评分

关闭自动操作，在新对局前连接捕获。建议卡及悬浮窗显示动作、候选百分比和权重条。
当前显示候选的百分比合计 100%，保留一位小数。默认按 q 的 softmax 换算，三麻温度为 1、四麻为 20，以适应当前模型的不同 q 尺度。
配置中可切回差值或原始 q。局中不显示 Token 用量；用量及原始候选仍保留在本机元数据，余额可在独立配置页查询。
立直宣言牌会复用本次返回，不再付费查询一次。
配合新版 AP 时，插件接收与当前事件同步的本机合法动作：无可用吃碰和时跳过；
立直后仅能摸切时直接显示摸切，不请求接口。有和牌、合法暗杠或拔北选择时仍查询。
缺少合法动作信息时保守查询，避免遗漏选择。历史事件仍完整保存并传给下一次查询。
不同吃法显示实际三张牌组；多个加杠候选分别显示加杠牌，保留赤牌。建议牌图使用已解码缓存，避免新评分配旧牌图。

直连提前建立 TLS 并采用 HTTP 连接复用。连接握手失败可在未发送请求前重建一次；发出付费请求后不自动重试。网络、模型推理和服务负载仍影响耗时。
默认响应等待上限为 4000 毫秒，正常回复会立即显示；单次直连请求的总等待预算为 4.4 秒，低于 AP 的 5 秒主程序上限。
超时不自动重发付费请求；同一份失败状态会缓存，可能已由服务器处理，以官方余额为准。
后续牌局状态可以继续查询，不受网络失败的一秒固定冷却影响；服务端明确返回的等待时间仍会遵守。
网络失败后后台仅重建 TLS 连接，不发送推理请求、不扣 Token。
余额不足、缺少完整小局历史、错误和模型未配置时不给出建议，不会回退到另一个人数的模型。

## 排查

默认直连 https://la.moxcomic.com，代理留空时不用系统代理。
代理仅支持 HTTP/HTTPS。使用代理时不保证复用连接。
settings.toml 和 .akagi 是本机私密配置，请勿上传分享。

只读查询：python configure.py --check
付费四麻测试：python configure.py --smoke
付费三麻测试：python configure.py --smoke --players 3

捕获中断后先恢复捕获；缺少起手事件时等待下一小局。
接口说明：https://moxcomic.github.io/archer/zh/guide/open-api

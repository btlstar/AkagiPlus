# 一番街本地装扮

在游戏原有界面选择角色、皮肤、头像、称号和装备，保存装扮方案与星标。核心换装已有用户实测，特殊皮肤同步、头像与语音等细节持续联调。补丁保留真实养成数值；最新修复的实际显示仍待确认。

## 使用

日常打开 AkagiPlus，在总览选择一番街并点击「启动游戏」，保留 Proxifier。装扮页提供安装/更新、还原与状态检查。游戏运行时禁止安装或还原。

生成补丁需要 `requirements.txt` 中固定版本的 UnityPy。可使用项目 Python，或在私人文件 `.local/riichicity-local-python.txt` 填写独立解释器路径；还原只需 Python 标准库。

## 文件职责

| 文件 | 用途 |
|---|---|
| `local_cosmetics.lua` | 唯一运行时逻辑：本地目录、选择保存、资料及消息外观处理 |
| `build.py` | 对已核对的原始客户端生成暂存包，保留其他脚本 |
| `install.py` | 版本校验、备份、原子替换及还原；由主目录管理入口调用 |
| `test_local.lua` / `test_lua.py` | 本地保存、消息入口和语音条件的快速回归 |
| `test_install.py` | 安装器改动时验证升级和恢复保护 |

只有一个游戏文件会被替换：`Mahjong-JP_Data/StreamingAssets/Base/lua_network`。安装器拒绝未知客户端更新或热更新覆盖；已知旧补丁可安全升级。GUI 的原始文件、暂存包和恢复记录放在当前用户 `AppData/Roaming/akagiplus/riichicity-local`；源码命令行旧记录保留在忽略提交的 `.local/`，不分发游戏资源。

游戏自带「安全模式」若包含自己，会在进入牌桌时将自身皮肤切回默认；要显示特殊皮肤，应关闭安全模式对自己的处理。它不影响候场和资料详情页，因此这两处正常不代表牌桌也会显示。补丁保留游戏原有的显示设置。

选择按账号存入 Unity PlayerPrefs；升级保留已有选择。补丁只处理本机外观，不修改抽卡、购买、奖励或对局牌和点数，也不改变外部 RiichiCityUnlock 授权模式。复杂随机方案仍待完整适配，目前使用指定项。

## 开发

只改 Lua 时，在私人目录生成一次暂存包并运行一次 `test_lua.py <游戏目录> --bundle <暂存包>`，通过后安装同一包。修改安装器时再运行 `test_install.py`；无需因此重编译 Rust、前端或重测整个代理链路。

客户端日志使用 `[AkagiPlus LocalCosmetics] installed v<版本>` 标记。语音试听仅取消本地语音目录的好感度/觉醒条件，保留真实好感度和节日条件；它不代表服务端获得觉醒或奖励。

“当前使用雀士头像”使用包含角色、皮肤与形态的编码 ID。补丁在本地随大厅主雀士重算该 ID，并刷新原生资料缓存；普通固定头像仍独立选择。对应客户端解码检查通过，真实界面效果待复测。
